# Web icon source

`Rakazo.icon/Assets/orange-bot.png` is the editable foreground source used by the web icon exports.
The character sits 90 points below center over the shared dark background token.

Run `pnpm --filter @rakazo/ui-tokens export:brand` to refresh the web favicons and install icons.
Small browser marks use a rounded mask; install icons use the square background.
